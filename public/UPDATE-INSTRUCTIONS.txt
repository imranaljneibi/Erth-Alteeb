تحديث فواتير العملاء — إرث الطيب

الملفات المعدّلة:
public/app.js
public/styles.css
tests/frontend.test.mjs

التثبيت:
1. فك ضغط الحزمة.
2. افتح مستودع Erth-Alteeb على GitHub ثم افتح مجلد public.
3. اختر Add file → Upload files وارفع app.js وstyles.css من مجلد public داخل الحزمة، ثم Commit changes.
4. افتح مجلد tests في GitHub وارفع frontend.test.mjs من مجلد tests داخل الحزمة ثم Commit changes.
5. افتح خدمة ERTH ALTEEB الحالية على Render واختر Manual Deploy → Deploy latest commit.
6. انتظر Live ثم حدّث الصفحة. من المبيعات اضغط أيقونة الطابعة بجانب العملية، ثم طباعة / حفظ PDF.
7. من نافذة الطباعة اختر الطابعة أو Save as PDF. يمكن تعطيل ترويسات المتصفح وتذييلاته لإخفاء عنوان الموقع من النسخة المطبوعة.

السلوك:
- فاتورة مستقلة لكل عملية بيع (العملية الحالية تحتوي منتجًا واحدًا بكمية محددة).
- رقم مرجعي ثابت مشتق من معرف البيع، وتاريخ البيع واسم العميل والمنتج والكمية والأسعار والعملة.
- إجمالي المدفوع من الدفعات المسجلة لتلك العملية والمتبقي؛ جلب البيانات من الخادم قبل الطباعة.
- لا تُعرض تكلفة المنتج أو الأرباح أو الملاحظات الداخلية للعميل.
- شعار الملف الأصلي بقص دائري عبر CSS، وتنسيق عربي A4.
- لا تغيير في قاعدة البيانات أو بيانات الدخول أو إعدادات الاستضافة.
- لا إنشاء أو احتساب ضريبة ضمن هذا التحديث.
- الطباعة لا تسجل عملية مالية إضافية. إعادة الطباعة تعكس البيانات الحالية وليست نسخة مؤرشفة من فاتورة سابقة.

التحقق:
نجح npm run check و18 اختبارًا. اختبار الفاتورة يغطي المدفوع جزئيًا والكامل، وتعديل كمية البيع، وحذف الدفعات والبيع، وثبات المرجع، وإخفاء معلومات التكلفة والملاحظات، وترميز مدخلات العميل والمنتج لمنع حقن HTML.
لم تتوفر أداة متصفح لفحص تخطيط الطباعة بصريًا؛ تحقق من معاينة الطباعة بعد النشر قبل تسليم أول فاتورة.
